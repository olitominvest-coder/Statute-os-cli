# Support

## Questions / help

- Search existing GitHub issues first.
- If you’re stuck, open a new issue with:
  - the command you ran
  - expected vs actual behavior
  - your OS + Node version
  - (optional) `--debug` output

## Bugs

Please use the bug report issue template when possible.

## Feature requests

Feature requests are welcome. Include the workflow you want to enable and any constraints (offline vs server, output format, CI requirements).

# Security Policy

## Supported Versions

Security fixes are applied to the latest published npm version of `statute-os`.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead:

1. Use GitHub’s **Private Vulnerability Reporting** (Security Advisories) for this repository, if enabled.
2. If that is not available, contact the maintainers by opening a minimal issue that requests a private channel (do not include exploit details) and we will follow up.

When reporting, include:

- A clear description of the issue and potential impact
- Reproduction steps or a proof-of-concept (if safe to share privately)
- Affected version(s)
